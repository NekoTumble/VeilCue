## 怎么签

1. 在本仓库发起 Pull Request 时，**CLA Assistant** 会自动在 PR 里评论并要求签署；
2. 按提示用 GitHub 账号授权签署（签署状态与账号绑定，**覆盖你过去、现在、未来的所有贡献**，
   不需要每次 PR 重复签）；
3. 未签署的 PR 会被标记并阻止合并。

> 企业贡献者：如需 Corporate CLA（CCLA），请通过 Issue 联系项目所有者。
